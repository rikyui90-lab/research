# 不祥事会社の株価推移ページを作る

発生日の前営業日の終値を基準に、最新終値までの騰落率を会社ごとに見せる単一 HTML(`fushoji-stock-trend.html`)を作る。
ひな形は `assets/template.html`。構成は、会社ごとのカード(事案の説明・SVG 日足チャート・統計・日次表)とフッター。騰落率の比較バーは置かない。

## 元データの収集(ニュース)

ユーザーが会社を指定していない場合や「ニュースをまとめて」と頼まれた場合は、最初に不祥事ニュースを集める。WebSearch を使う。

検索キーワード(どれか1つ以上を含む記事を対象にする):
不正 / 改ざん / 漏えい / 横領 / 粉飾 / リコール / 行政処分 / 業務停止 / コンプライアンス違反 / ハラスメント / 調査委員会 / 再発防止策 / 第三者委員会

- 「キーワード + 企業 + 発表」「キーワード + 直近の年月」などで検索し、キーワードごとに調べる。
- 1社1件にまとめる。同じ事案の記事は統合する。
- 事案ごとに次を拾う: 会社名、証券コード(上場なら)、発生・発表日、内容の要約(2〜3文)、該当キーワード、出典 URL。
- 発生日は「公表日」を優先する。日付が記事から確定できないものは、推測せず空欄にしてユーザーに聞く。
- 上場していない会社は、親会社などの代替株価を使うか、対象外にするかをユーザーに確認する。
- 集めた一覧(会社名・発生日・要約・出典)を先にユーザーへ見せ、掲載する会社を選んでもらってから、次の手順に進む。

## 入力として必要なもの

会社ごとに次を集める(ニュース収集で埋まる項目はそのまま使う)。足りなければユーザーに聞く。

- 会社名、証券コード、市場(東証/NYSE など)
- 発生日(`YYYY-MM-DD`)と表示用ラベル(例: `2026年9月29日・30日`)
- 事案の説明文(ニュース記事の要約、またはユーザーのメモをそのまま使う)
- 出典(ニュース記事の URL と媒体名。カードの注記か、フッターに載せる)
- 注記(あれば)

## 手順

ページは `scripts/build_pages.py` が、会社データ(`companies.json`)から生成する。HTML を手で書き換えない。

1. 会社データ `companies.json` を作る(既存なら追記する)。1社1オブジェクトで、項目は次のとおり。
   - `id, name, code, sym, market, cur('JPY'|'USD'), tags, eventDate, eventLabel, body, notes`
   - `sources`: `[{"label": "媒体名(日付)", "url": "..."}]`。出典 URL は必ず付ける。
   - `sym` は Yahoo のシンボル。東証は `6594.T`、米国株はティッカーのまま。
2. 生成する。
   ```
   python <このスキルのパス>/scripts/build_pages.py <companies.json> <出力フォルダ>
   ```
   - 株価を Yahoo Finance から取得し、出力フォルダの `prices.json` に保存する。取得し直さないときは `--use-cache` を付ける。
   - 出力は、四半期ごとのページ(`2026-q3.html` など)と、`index.html`。
   - `index.html` の四半期の見出しは、その四半期の全社のページへ、会社名は、その会社だけを表示するページ(`2026-q3.html?c=<会社のid>`)へのリンク。
   - 四半期は発生日の暦年の四半期で分ける。ページ内の並びは発生日の新しい順。
   - 配当・分割の調整はしない。取引中は最新日の値が確定前になる。取得は市場が引けた後に行う。
   - 市場が引ける前は `--until <前営業日>` を付けて、確定した終値だけを使う。発生日の終値がまだない会社は載らず、警告が出る。
3. ブラウザで開き、次を確認する。
   - `index.html` から四半期のページと、会社名の絞り込み表示(`?c=`)に移れて、戻るリンクも動く。
   - 全カードにチャートが出ている。
   - 1か月/3か月/6か月/1年の切り替えで崩れない。
   - ダーク/ライトの両テーマで読める。
   - ホバーのツールチップが出る。
   - スマホ幅(約375px)で横スクロールが出ない。

## 自動更新(タスクスケジューラ)

平日16時に、Windows のタスク `fushoji-update-pages` が `scripts/update_pages.ps1` を実行し、株価を取得し直して `fushoji/` の全ページを作り直す。

- ログは `fushoji/update.log`(Git には入れない)。終了コードが 0 でなければ失敗。
- 取得に失敗したときは、既存のページを書き換えずに止まる。
- コミットは自動では行わない。更新後の差分は、必要なときに手でコミットする。
- 会社を足すときは `fushoji/companies.json` に追記する。次の自動更新で、ページに反映される。
- 手動で今すぐ実行する: `powershell -File <このスキルのパス>/scripts/update_pages.ps1`
- タスクの確認・停止: `Get-ScheduledTask fushoji-update-pages` / `Unregister-ScheduledTask fushoji-update-pages`
- Yahoo Finance の API は非公式。急に取得できなくなる可能性がある。

ひな形(`assets/template.html`)を直すときは、`__TITLE__` などのプレースホルダを消さない。

## 守ること

- 基準は「発生日の前営業日の終値」。`metrics()` の `idx - 1` がそれ。発生日が休場日でも、次の営業日の行が `idx` になるので結果は正しい。
- 非上場会社は対象外にする(代替の株価は使わない)。上場している親会社の事業で起きた事案は、上場会社の名前で載せ、`tags` と `notes` に株価がどの会社のものかを書く(タイムカーとパーク24が例)。
- 株価が10円台などの低位株は、1円の変動が数%になる。`notes` に注意書きを入れる。
- 発生前5営業日に±10%以上の動きがある銘柄は、カードに自動で注記が出る。消さない。
- 不祥事の内容は、各カードの出典を要約したもので、独自の事実確認はしていない。この旨のフッターは生成スクリプトが入れる。投資助言ではない旨も残す。
- 発生日は、個別の記事や適時開示で確認できたものだけを使う。確認できない会社は載せない。一覧サイトの日付しかないものは `notes` にその旨を書く。
- 同じ会社の事案が複数回公表されている場合は、載せた日付と、それ以外の公表日を `notes` に書く。
- 記事に書かれていない内容(金額、人数、原因)を補わない。報道の段階のもの(「検討中と報道」など)は、断定せず報道であることを書く。
- チャートの印は、最大上昇が赤丸、最大下落が黒丸。発生日と同じ日は出さない。
- 会社名は赤字(CSS 変数 `--company`)。デザインを変える依頼がない限り維持する。
- 外部ライブラリは使わず、チャートは自前の SVG で描く。
