- 記録日: 2026-10-09
- 作り方: 証券会社・取引所などの解説ページを読み、自分の言葉で書いた。文章は写していない。調査と文章づくりは Claude のエージェントが行い、別のエージェントが事実確認した。
- URL の確認(節1〜3): 次の3件の babypips の URL は、スクリプトからのアクセスでは 403 が返る(事実確認の担当者は、ブラウザのツールで読んだ)。ほかに挙げた URL は、2026-10-09 に HTTP 200 が返ることを確認した。

- 出典が空の項目は、一般的な知識で書いたもので、出典ページでは確認できていない。その旨を備考に書いた。
- 複数の URL は「; 」で区切って並べた。出典の文章はここに写していない。

## 6. 株価予想(2026-10-09 追加)

- 対象: 株価予想モードの20問・55個の例(`FORECAST_QUESTIONS`)。各例の指標の値を、どの数字から計算したかを記録する。
- 株価は、ページではなく、Yahoo Finance(Yahoo Inc. の非公式な chart API。`https://query1.finance.yahoo.com/v8/finance/chart/<コード>.T`)から、2026-10-09 に curl で取得した。**この API の利用条件(再配布・埋め込みが許されるか)は確認できていない。公開の前に、ユーザーが利用条件を確認すること。** 日本版の「Yahoo!ファイナンス」の注記ページは株式情報の転用・販売を禁じ、情報提供元に取引所などを挙げているので、画面の表記は取得元の実態に合わせて「Yahoo Finance(株式分割を調整した、週ごとの終値)」とした。配当は含まない。終値は株式分割を調整した値で、指標の計算には、分割の倍率を掛けて戻した(その日に実際についていた)株価を使った。株価のページ(`finance.yahoo.co.jp/quote/…/history`)は開いていないので、出典には入れていない。
- 計算に使った数字の出典は、決算短信のPDF(福岡証券取引所が公開しているファイルと、各社のIR)。PDFは、抽出したテキストとして読んだもので、画面で見て確かめたものではない。
- 未確認の点:
  - 三菱商事(8058)の2019年3月期の短信は「平成31年3月期」の表記で、公表日が文面から確認できていない(cyclical-low-per の例)

  - 住友電気工業(5802)・トヨタ自動車(7203)など、株式分割があった銘柄の分割の倍率と効力発生日は、公式の資料では確認していない(株価データの調整前後の値から求めた倍率を使った)。日本製鉄(5401)は、説明資料(`https://www.nipponsteel.com/ir/library/pdf/20250801_600.pdf`、2025年度1Q決算説明会資料)を開いて確かめ、「2025年10月1日を効力発生日として、1株を5株とする株式分割」の記載があったので、出典に残した
