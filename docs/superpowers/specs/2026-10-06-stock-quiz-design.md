# 株クイズゲーム 設計書

作成日: 2026-10-06
状態: 設計承認済み(設計書のレビュー待ち)。用語クイズを120問に増やし、解説画面に「くわしく」欄を足した内容(v5)を反映済み

## 1. 目的

株の知識を学べるクイズゲームを、Web で公開して広く遊んでもらう。
チャートの形状(形の名前)、その後の値動き、ローソク足、用語の4種類を出題する。

### 決まっていること

- チャートはプログラムで生成する(実在の銘柄・実データは使わない)
- ランキングなし。スコアはブラウザの `localStorage` に保存するだけで、サーバーは使わない
- 作り方は単一 HTML(HTML + CSS + JavaScript + Canvas/SVG の1ファイル)
- 公開は GitHub Pages を想定するが、公開作業は本設計の範囲外(ユーザーが明示的に許可するまで行わない)

### 範囲外(作らないもの)

ランキング、ログイン、広告、課金、実データの取り込み、問題の自動配信。

## 2. 免責

「学習用のゲームです。実際の相場では必ずこの通りに動くとは限りません。投資の助言ではありません。」を全画面の下部に常時表示する。
値動き予想の正解は「教科書的な傾向」であり、実際の相場の予測ではない。

## 3. ゲームの流れ

1. **スタート画面**: タイトル、難易度の選択、出題モードの選択、最高スコア
   - モード: 全部まぜ / チャートの形状 / 値動き予想 / ローソク足 / 用語
   - 難易度: すべて / ★ / ★★ / ★★★ / ★★★★ / ★★★★★ の6つ(出題モードと組み合わせて使う。選んだ難易度は、ページを開いているあいだ保つ。折り返して、スマホ幅でも横スクロールしない)
   - 各モードのボタンに、選んだ難易度での最高スコア・正解率・そのラウンドの問題数を表示する
2. **ラウンド**: 1ラウンドは最大10問。選んだモードと難易度に該当する問題からランダムに選ぶ(重複なし)。該当する問題が10問に満たない場合は、その数が1ラウンドの問題数になる(どの組み合わせも1問以上ある。★★★★・★★★★★ は新しい問題だけで構成されるため、チャートの形状・値動き予想・ローソク足のように問題が少ない組み合わせでも「あるだけで出題」する。用語は ★★★★・★★★★★ でも20問ずつあり、10問になる)。つまり、1ラウンドの問題数は min(10, モード × 難易度の問題数) である
   - 「全部まぜ」では、チャートの各パターンが出すのは、チャートの形状か値動き予想のどちらか1問だけ(両方は出さない。片方の解説がもう片方の答えになるため)。難易度で絞り込んだ場合も同じで、そのパターンが選ばれた難易度に含まれるなら、ラウンドごとにどちらか1問だけが入る
   - 観察(仕様の変更ではない): 用語が120問になったため、難易度が「すべて」の「全部まぜ」の候補は、チャートの形30 + ローソク足30 + 用語120 の180問で、約3分の2が用語になる。★★★★・★★★★★ の候補も、用語20 + ローソク足2 + チャート2 の24問で、同じく用語が大半を占める。出題の偏りを変えたい場合は、別の仕様変更として検討する
3. **1問ごと**:
   - 問題を表示する(チャートは Canvas または SVG で描く)
   - 4択(値動き予想は3択)で答える
   - すぐに解説画面を出す
   - 画面を描いた直後の400ミリ秒間は、クリックを無視する(ダブルクリックの2回目で、次の問題の答えや「次の問題へ」を誤って押さないため)
   - 問題画面と解説画面には、問題番号の横に難易度(★ から ★★★★★ まで)を表示する
   - 問題画面と解説画面の上部に「← トップに戻る」を置く。押すと画面の中に確認(「今のラウンドは途中でやめるよ。トップに戻っていい?」、ボタンは「やめてトップへ」/「続ける」)を出す。「やめてトップへ」を選ぶとそのラウンドを破棄してスタート画面に戻り、成績(最高スコア・正解率)は記録しない。確認を出している間は、選択肢や「次の問題へ」は答えとして扱わない。確認が開いた直後と閉じた直後の400ミリ秒間も、クリックを無視する
4. **解説画面**:
   - 正解の名前を大きく表示する(例:「ダブルトップ」)
   - 解説を1〜2行で表示する
   - 解説の下に「くわしく」欄を表示する(詳しくは「「くわしく」欄」を参照)
   - 不正解のときは「あなたの答え: ○○」を併記する
   - 値動き予想の問題では、正解の方向(上がりやすい / 下がりやすい / 横ばい)も表示し、続きの値動きを点線で描く
   - 「次の問題へ」ボタン
5. **結果画面**: 正解数、間違えた問題の一覧(復習用。各行に難易度の星を付ける)、「間違えた問題だけやり直す」ボタン(間違いが1問以上あるときだけ)、もう一度ボタン、トップへ戻るボタン、結果のテキストコピー
   - 結果のテキストには、モード名に加えて難易度の星を含める(難易度が「すべて」のときは星を付けない。例: 「株クイズ(チャートの形状・★★)で 10問中7問正解!」)
6. **やり直し**: 「間違えた問題だけやり直す」を押すと、そのラウンドで間違えた問題だけで新しいラウンドを始める。
   - 問題とチャートは元のラウンドと同じ。選択肢の並びは入れ替える(値動き予想だけは固定順のまま)
   - 画面には「やり直し 問題 n / N」と表示する
   - やり直しのラウンドは、最高スコアにも正解率にも入れない。結果画面には、そのことを注記する
   - やり直しの結果でまだ間違えた問題があれば、「まだ間違えた問題をやり直す」で何度でも繰り返せる
   - やり直しの結果画面には「結果をコピー」を出さない。「新しいラウンドを始める」で通常のラウンドに戻る
7. **保存**: 最高スコアとモード×難易度ごとの正解率を `localStorage` に保存する。保存のキーは、難易度が「すべて」ならモード名そのまま、それ以外は `モード名:難易度`(`pattern:easy` など。内部の難易度の値は `easy` / `normal` / `hard` / `expert` / `master`)。難易度の指定がない古い保存データは「すべて」として読む

## 4. 問題の種類

| type | 内容 | チャート |
|------|------|----------|
| `pattern` | 完成したチャートを見せて、形の名前を4択で答える | あり |
| `outlook` | チャートを途中まで見せて、上がる / 下がる / 横ばいを答える。回答後に続きを描く | あり |
| `candle` | 1〜5本のローソク足を見せて、名前を4択で答える | あり |
| `term` | 用語の意味を4択で答える | なし |

## 5. チャート生成

- パターンごとに「形の骨格」(山と谷の位置の並び)を定義する。
  例: ダブルトップ = 上昇 → 高値 → 押し → 同じ高さの高値 → 下落
- 骨格の点のあいだを、単調3次補間(PCHIP)でなめらかにつなぐ。点の数は120点(値動き予想の続きは30点)
- そこへ、なめらかなゆらぎ(AR(1) で作るノイズ)を足す
- 移動平均線は短期10・中期30・長期60の3本を計算する。ゴールデンクロス・デッドクロスと、2つのパーフェクトオーダーのチャートに付け、クロスは短期と中期の交差である。色は短期が橙、中期が緑、長期が紫で、線の右端に「短」「中」「長」の文字を添え、チャートの下に色の説明を書く(解説文は「中期」の移動平均線と書く)
- 乱数はシード付きの擬似乱数を使い、問題ごとにシードを持つ。同じシードなら同じチャートになる
- 描画は、点を曲線でつないだ折れ線(曲線描画)とローソク足の両方に対応する

### ローソク足の収録

30種類を収録する。当初の10種類に、次の10種類(第2弾)と、さらに次の10種類(第3弾)を加えた。

- 第2弾: 宵の明星、強気のはらみ足、弱気のはらみ足、毛抜き天井、毛抜き底、切り込み線、かぶせ線、トンボ、塔婆、コマ
- 第3弾: 下影陽線、上影陰線、上窓(ギャップアップ)、下窓(ギャップダウン)、強気のはらみ十字、弱気のはらみ十字、上げ三法、下げ三法、捨て子線(底)、捨て子線(天井)

第3弾の定義の要点は次のとおりである。

- 下影陽線 / 上影陰線: 1本。実体は値幅の 30〜50%、ヒゲは実体より長く、反対側のヒゲはほとんどない(ハンマー・流れ星より実体が大きい)
- 上窓 / 下窓: 2本。上窓は2本目の安値が1本目の高値より上、下窓は2本目の高値が1本目の安値より下に離れる(窓)
- 強気 / 弱気のはらみ十字: 2本。1本目の大きな実体の中に、2本目の十字線(始値と終値が同じ)が収まる。1本目は強気が陰線、弱気が陽線
- 上げ三法 / 下げ三法: 5本。1本目の大きな実体のあと、小さな実体の3本が1本目の値幅の内側で少しずつ逆向きに動き、5本目が1本目の終値を超えて引ける
- 捨て子線(底 / 天井): 3本。十字線が前後の足と、どちらも窓を空けて孤立する(底は下に、天井は上に)

### 紛らわしい選択肢の組

名前が似ている・見た目が近い組は `CONFUSABLE_PAIRS` に定義する(例: 三角持ち合いとペナント、十字線とトンボ・塔婆、毛抜き天井とかぶせ線)。新しい項目では、見た目が近い組(窓を含む星と捨て子線、はらみ足とはらみ十字、ハンマーと下影陽線、パーフェクトオーダーとゴールデン/デッドクロス・チャネル、ダイヤモンドと対称三角形・三尊など)を足した。選択肢を作るときに、正解と紛らわしい組になるものを、間違いの選択肢の候補から除外する。除外するのは「正解の項目と紛らわしい組」だけなので、間違いの選択肢どうしが紛らわしい組になることはありうる(4つの選択肢全体で、紛らわしい組が同時に並ばないことまでは保証しない)。

### 難易度

難易度は5段階で、画面には ★ / ★★ / ★★★ / ★★★★ / ★★★★★ とだけ表示する(内部の値は `easy` / `normal` / `hard` / `expert` / `master`。絞り込みの「すべて」は `all`。読み上げ用の説明は「難易度 星Nつ(5段階)」)。スタート画面の切り替えは「すべて」と5段階の6つである。

- チャートのパターン、ローソク足、用語のすべてに難易度を付ける。個数は次のとおり(種類ごと)

| 難易度 | 用語 | ローソク足 | チャートの形 |
|--------|------|------------|--------------|
| ★ | 27 | 9 | 9 |
| ★★ | 27 | 9 | 9 |
| ★★★ | 26 | 8 | 8 |
| ★★★★ | 20 | 2 | 2 |
| ★★★★★ | 20 | 2 | 2 |
| 計 | 120 | 30 | 30 |

- 値動き予想の問題は、元のパターンの難易度をそのまま使う。三角持ち合い(★★)は値動き予想に出さないので、値動き予想は ★ 9 / ★★ 8 / ★★★ 8 / ★★★★ 2 / ★★★★★ 2 の計29問になる
- ★★★★・★★★★★ は新しい問題だけで構成する。問題が少ない組み合わせ(ローソク足2・チャート2 など)があっても、あるだけで出題する。どの組み合わせも1問以上あり、★ から ★★★ では6問以上ある。用語は ★★★★・★★★★★ でも20問ずつある
- 「全部まぜ」の ★★★★・★★★★★ は、用語20 + ローソク足2 + チャート2(形状か値動きの一方)の24問が候補になり、1ラウンドは10問になる
- 各難易度には、v4 の追加分として、次の10問が入っている(用語4 + ローソク足2 + チャート2種類 × 形状と値動き予想の2問)。この10問は、v5 で用語を足しても変わらない

| 難易度 | 用語(4) | ローソク足(2) | チャートの形(2) |
|--------|---------|----------------|------------------|
| ★ | 配当、株主優待、上場、単元株 | 下影陽線、上影陰線 | 上昇チャネル、下降チャネル |
| ★★ | 損切り、利益確定、ナンピン、塩漬け | 上窓、下窓 | Vボトム、Vトップ |
| ★★★ | 板、約定、寄り付きと大引け、前場と後場 | 強気のはらみ十字、弱気のはらみ十字 | 上昇パーフェクトオーダー、下降パーフェクトオーダー |
| ★★★★ | 信用倍率、逆日歩、ROA、EPS | 上げ三法、下げ三法 | ラウンドトップ、逆カップウィズハンドル |
| ★★★★★ | 配当性向、自社株買い、株式分割、サーキットブレーカー | 捨て子線(底)、捨て子線(天井) | ダイヤモンドトップ、ダイヤモンドボトム |

- v5 では、用語クイズを80問(用語50・テクニカル30)追加した。各難易度に、用語10問とテクニカル6問の計16問が入る(用語の個数は、v4 までの40問に各難易度16問を足して、27 / 27 / 26 / 20 / 20 問になる)。追加した80問の話題は次のとおりである(「用語」は用語・制度・指標など、「テクニカル」はテクニカル分析の指標・考え方)

| 難易度 | 用語(10) | テクニカル(6) |
|--------|----------|---------------|
| ★ | 株式、投資信託、ETF(上場投資信託)、証券取引所、IPO(新規公開株)、プライム市場、キャピタルゲイン、強気(強気相場)、証券コード(銘柄コード)、ドル・コスト平均法 | テクニカル分析、トレンド(上昇トレンド)、サポートラインとレジスタンスライン、トレンドライン、日足・週足・月足、オシレーター系指標 |
| ★★ | TOPIX(東証株価指数)、特定口座、年初来高値、増資、株主総会、議決権、売買代金、自己資本比率、優先株、REIT(不動産投資信託) | RSI(相対力指数)、MACD、ボリンジャーバンド、移動平均乖離率、サイコロジカルライン、ブレイクアウト |
| ★★★ | BPS(1株当たり純資産)、TOB(株式公開買付け)、PTS(私設取引システム)、有価証券報告書、転換社債型新株予約権付社債(CB)、ストックオプション、第三者割当増資、ブックビルディング方式、追証(追加証拠金)、貸株 | ストキャスティクス、一目均衡表の「雲」、ダウ理論、パラボリック(SAR)、VWAP(出来高加重平均価格)、モメンタム |
| ★★★★ | EBITDA、PEGレシオ、DOE(株主資本配当率)、フリーキャッシュフロー、ROIC(投下資本利益率)、ベータ値、株価指数先物取引、オプション取引(コールとプット)、流動比率、インタレスト・カバレッジ・レシオ | DMI(+DI・-DI・ADX)、フィボナッチ・リトレースメント、騰落レシオ、ボリュームレシオ、ATR(アベレージ・トゥルー・レンジ)、CCI(商品チャネル指数) |
| ★★★★★ | シャープ・レシオ、DCF法、WACC(加重平均資本コスト)、のれん(のれん代)、株式持ち合い(政策保有株)、ポイズンピル(毒薬条項)、スクイーズアウト、日経平均ボラティリティー・インデックス(日経平均VI)、踏み上げ、コーポレートガバナンス・コード | エリオット波動、ダイバージェンス(逆行現象)、平均足、ポイント・アンド・フィギュア、RCI(順位相関指数)、価格帯別出来高 |

- 難易度の割り当ては、データのブロックの表(`DIFFICULTY_BY_ID`)で決める。表にない項目はテストで不備として見つける
- 難易度が「すべて」の出題は、難易度を導入する前と同じ内容になる

新しいチャートの形の定義の要点は次のとおりである。

- 上昇チャネル / 下降チャネル: 平行な右上がり(右下がり)の2本の線のあいだで、高値と安値を切り上げ(切り下げ)ながら上下に振れる
- Vボトム / Vトップ: 急落(急騰)のあと急反発(急落)し、底(天井)が尖っている。丸底・丸天井ではない
- 上昇 / 下降パーフェクトオーダー: 移動平均線(短期10・中期30・長期60)が、上から 短期 > 中期 > 長期(下降は長期 > 中期 > 短期)の順に並び、3本とも右上がり(右下がり)になる。移動平均線つきで、凡例を出す
- ラウンドトップ: ゆるやかに上がって丸い天井をつけ、ゆるやかに下がる。山が1つで、左右がほぼ対称
- 逆カップウィズハンドル: 丸い山のあと、小さな戻り(取っ手)を作る、カップウィズハンドルの上下を逆にした形
- ダイヤモンドトップ / ボトム: 高値圏(安値圏)で値幅が広がってから狭まり、ひし形を描いて、下(上)に抜ける

### 値動き予想の続きの生成

パターンの `outlook` の方向へ動く値動きを、ノイズつきでランダムに生成する。
方向は必ず `outlook` と一致させる(チャートが答えと矛盾しないようにする)。

## 6. 問題データ

問題は1つの配列にまとめ、1問ごとに次の項目を持つ。

- `type`: `pattern` / `outlook` / `candle` / `term`
- `id`: 一意の文字列
- `difficulty`: `easy` / `normal` / `hard` / `expert` / `master`
- `pattern`: パターン名(`pattern` と `outlook` のみ)
- `seed`: チャート生成のシード(チャートのある問題のみ)
- `question`: 問題文
- `choices`: 選択肢(`outlook` は3つ、それ以外は4つ。正解を1つ含み、重複しない)
- `answer`: 正解の選択肢
- `explanation`: 解説(1〜2行)
- `detail`: 「くわしく」の文(必須。`validateQuestion` は、`detail` が無い、または空の問題を不備として見つける)
- `outlook`: `up` / `down` / `flat`(`outlook` のみ)
- `category`: `term` / `technical`(データの項目にだけ持つ。v5 で追加した用語80問が持ち、用語50問が `term`、テクニカル30問が `technical`。出題の動きは変えない。既存の40問には付けない)

選択肢の並び順は、`pattern` / `candle` / `term` は出題のたびにシャッフルする。`outlook` は「上がりやすい / 下がりやすい / 横ばい」の固定順にする。
`pattern` / `outlook` の問題は、パターン定義から自動で作る。
`candle` と `term` の問題は、手で書いたデータを入れる(`candle` 30問、`term` 120問。`term` は、既存の40問に、v5 で足した80問を加えたもの)。

### 「くわしく」欄

- 解説画面で、解説の下に「くわしく」という見出しの枠を出し、`detail` の文を表示する。解説よりも踏み込んで、なぜそうなのか・実際にどう使われるか・注意点(ダマシや勘違い)を2つ以上書く
- 文章は120〜250字・2〜4文で、句点で終える。解説と同じ内容を繰り返さない。「必ず」「絶対」「買うべき」「売るべき」のような断定や助言の言葉は使わない。180項目で、すべて違う文にする
- チャートの形(30)は、形状の問題と値動き予想の問題で同じ `detail` を使う(パターン定義に1つ持つ)。そのため、形そのものの説明にし、特定の問題を指す言い方(「正解」「この問題」)は使わない。ローソク足(30)も同じ
- 既存の100項目(チャートの形30・ローソク足30・用語40)の `detail` は、データのブロックの表 `DETAIL_BY_ID`(形・ローソク足・用語に分けた表)に持ち、`assignDetail` で各項目に付ける(`DIFFICULTY_BY_ID` と `assignDifficulty` と同じ作り)。表にない項目には付かず、`validateQuestion` が不備として見つける。追加の用語80問は、`TERMS` の各項目に `detail` を直接書き、`DETAIL_BY_ID` には入れない
- 文章は、証券会社・取引所などの解説ページを読んで、自分の言葉で書き直したもので、出典の文を写していない。内容の出典の URL は `docs/superpowers/sources/2026-10-09-quiz-sources.md` に記録している(出典の URL は画面には出さない)

## 7. ファイル構成

- 配置: `stock-quiz/index.html`(既存の不祥事ページとは混ぜない)
- `index.html` の中のコードを3つのブロックに分ける。
  - **データ**: 問題データ、パターン定義
  - **ロジック**: 乱数、チャート生成、出題、採点、選択肢の作成(画面に依存しない純粋な関数)
  - **画面**: 描画、ボタン操作、`localStorage` の読み書き
- データとロジックのブロックは、`// ==DATA-START==` / `// ==DATA-END==` と `// ==LOGIC-START==` / `// ==LOGIC-END==` のコメントで囲む(テストが取り出すための目印)。画面のブロックは `// ==UI-START==` / `// ==UI-END==` で囲む

## 8. テスト

- ロジックの単体テストは `stock-quiz/tests/logic.test.js` に置き、Node 標準の `node:test` で動かす(外部パッケージは使わない)。
- テストは `index.html` を読み込み、`DATA-START` と `DATA-END` のあいだ、`LOGIC-START` と `LOGIC-END` のあいだ(データとロジックのブロック)を取り出して評価する。
- 確認する内容:
  - 同じシードなら同じチャートが生成される
  - 続きの値動きの方向が `outlook` と一致する
  - すべての問題で、選択肢が4つ(値動き予想は3つ)で重複がなく、正解が1つだけ含まれ、難易度が正しい値である
  - 全パターンに骨格と `outlook` が定義されている
  - 1ラウンドの問題に重複がない。1ラウンドの問題数が、モード × 難易度のすべての組み合わせで min(10, 該当する問題数) になり、どの組み合わせも1問以上ある(期待値は、チャートの形状・ローソク足が 9 / 9 / 8 / 2 / 2、用語が 27 / 27 / 26 / 20 / 20、値動き予想が 9 / 8 / 8 / 2 / 2)。「全部まぜ」の ★★★★・★★★★★ は候補が24問あり、1ラウンドは10問になる
  - 各難易度に、v4 で追加した問題がちょうど10問ある(v4 の新しい項目の id を数える。v5 の用語は数えない)
  - 「くわしく」の網羅: チャートの形30・ローソク足30・用語120の全180項目に、空でない `detail` がある。`DETAIL_BY_ID` のキーは、既存の100項目(用語は最初の40問)とちょうど一致し、追加の80問は含まない。追加の80問は、自分の `detail` を持つ
  - 「くわしく」の質: 120〜250字、2〜4文、句点で終わる。180個がすべて違い、解説と同じ文・解説を含む文がない。「必ず」「絶対」「買うべき」「売るべき」を `detail` と `explanation` に含まない(`bull-market` の「絶対に続くとは限らない」だけは、否定の形の注意なので許す)。チャートの形とローソク足の `detail` は「正解」「この問題」を含まない。`detail` が無い問題を `validateQuestion` が不備とする。形状と値動き予想が同じ `detail` を使う
  - 追加の用語80問: id が重複せず既存の40問と重ならない。`category` が `term` か `technical` で、50問と30問。各難易度に用語10問とテクニカル6問があり、id の表と一致する。選択肢が4つで重複せず、解説が1〜2文。正解が選択肢の中で唯一いちばん長い問題は、全体で30問以内、各難易度で8問以内。どの項目から作った問題も `validateQuestion` を通り、難易度と `detail` を持つ
  - 難易度の表: 全パターン・全ローソク足・全用語に難易度が付き、種類ごとの個数が上の表のとおりである。値動き予想は元のパターンの難易度を使い、三角持ち合いを含まない
  - 難易度で絞ったデッキ: 問題がすべてその難易度で、重複がなく、同じシードなら同じになる。「全部まぜ」でも、同じ形の「チャートの形状」と「値動き予想」が同じラウンドに出ない
  - 保存のキー: `statsKey` と `STATS_KEYS` が、難易度つきのキーを含む。難易度のない古い保存データは「すべて」として読め、壊れたデータは正しい部分だけ使う。結果のテキストに難易度の星が入る
  - やり直しのデッキ: 間違えた問題だけが元の並びで入る。選択肢は入れ替わるが、集合と正解は変わらず、値動き予想は固定順のまま。全問正解なら空で、やり直しの結果からさらに絞り込める
  - 移動平均線が短期10・中期30・長期60の3本である(生成の定数を含む)
  - 紛らわしい組が、正解の項目の問題の選択肢に同時に出ない(新しい組を含む。両方向で確かめる)
  - 新しいローソク足10種類と、新しいチャート10種類の定義を、数値で確かめる(窓の大きさ、はらみ十字の収まり、三法の内側、捨て子線の孤立、チャネルの傾き、Vの尖り、パーフェクトオーダーの並びと傾き、丸天井の対称、ダイヤモンドの振れ幅など)。チャートの形は、乱数のシード300〜500通りで確かめる
- 画面はブラウザで実際に動かして確認する(スマホ幅を含む)。

## 9. 見た目

- 問題画面: 上部に問題番号・正解数・進捗バー、中央にチャート、下部に4択ボタン(値動き予想は3択)。上部の左に「← トップに戻る」、問題番号の横に難易度の星を置く
- 解説画面: 上部に正解の名前(大きく)と解説、その下にチャート、下部に「次の問題へ」
- 最下部に免責を常時表示する
- スマホ幅(375px)で横スクロールしない。ダークモードに対応する(`prefers-color-scheme`)
- 色だけで正誤を伝えない(「正解」「不正解」の文字も併記する)

## 10. エラー処理

- `localStorage` が使えない場合(プライベートモードなど)は、保存をあきらめて、ゲーム自体はそのまま動かす
- 各モードに最低10問を用意し、難易度を指定しないとき1ラウンド10問が必ず成立するようにする。難易度で絞り込むと問題数が10問に満たないことがあるが(チャートの形状・値動き予想・ローソク足の ★★★★・★★★★★ では2問)、どのモード × 難易度の組み合わせも1問以上を確保する(テストで問題数を確認する)。問題がない組み合わせのボタンは押せない状態にして「この難易度の問題は、まだないよ」と出す(現在は発生しない。念のための保護である)
- 「トップに戻る」の確認や、やり直しの開始のように、ダブルクリックで意図しない操作が起きうる画面では、描画直後の400ミリ秒間のクリックを無視する
